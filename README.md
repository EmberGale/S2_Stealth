# S2_Stealth
Задача: Реализуйте концепт, который придумал геймдизайнер, и соберите результат в небольшой MVP.

Пункты реализации:
- Здоровье персонажа
- Турель с двумя состояниями:
		- Патруль
		- Атака
- Открывающаяся дверь
- Нажимная плита
- ПИН-код панель
